# OKI · 小宁与小小世界

直接打开 `oki.html`，无需联网或构建。首页按照用户 Figma 35:3426 的街景、并列入口与输入区实现；实际小宁 3D 模型继续保留，不使用角色截图替代。

- 顶部省略号：小宁档案、功能、角色切换、设置。
- `settings.html`：独立设置页面，可返回首页，支持声音、降低透明度、聊天记录与记事本。
- 底部文字输入：发送到本地演示会话，使用预设回复。
- 麦克风：用户主动授权后可本地录制、试听并发送至当前会话；离开录音弹层释放麦克风，关闭消息弹层后不保留音频。需浏览器支持 MediaRecorder 与麦克风权限。
- 电话：界面演示，未接入实时通话服务。
- 两个并列入口：快捷记事本、小小世界。记事本和文字历史仅存在本地浏览器。
- UI 操作图标来自 Lucide；背景和入口图片为用户 Figma 的原始素材，来源见 `assets/UI-SOURCES.md`。
- 网页使用 CSS 透明材质近似玻璃效果，不调用原生 SwiftUI Liquid Glass API。系统降低透明度、高对比度和减少动画偏好有对应降级。

既有 `character.js`、`character-source.js`、`assets/character-data.js` 保持不变。`exam.txt` 未改，模块二未制作。
